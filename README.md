# AWS Notes

Hands-on AWS notes for beginners heading into DevOps. Every chapter comes from doing the work in a real AWS account: real labs, real outputs and the real mistakes.

**Read online:** https://usmanrangrez.github.io/aws-notes/

Chapters follow the order of M Prashant's [AWS in ONE VIDEO for Beginners](https://www.youtube.com/watch?v=N4sJj-SxX00), with extra topics from his [playlist](https://www.youtube.com/playlist?list=PL0tP8lerTbX3mKdZYfJwXcKf6SOfmQcgl), Abhishek Veeramalla's [AWS Zero to Hero](https://www.youtube.com/playlist?list=PLdpzxOOAlwvLNOxX0RfndiYSt1Le9azze) and Boot.dev's [Full AWS DevOps Course](https://www.youtube.com/watch?v=UcxXSHDDUE8). The notes are my own write-up, not transcripts.
