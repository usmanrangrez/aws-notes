01

Files and folders

Command Example Does
pwd pwd Which folder am I in
ls ✓ ls -la List files (-a shows hidden ones)
cd cd /var/log · cd .. · cd ~ Change folder
mkdir ✓ mkdir -p app/logs Create folder(s)
cp / mv ✓ cp -r src/ backup/ · mv a.txt b.txt Copy / move or rename
rm rm -r old/ Delete. No undo, check twice
cat ✓ · less cat file · less big.log Show a file / scroll through it
tail ✓ tail -f /var/log/app.log Last lines; -f = watch live
find find / -name "*.conf" 2>/dev/null Search files by name
df ✓ / du df -h · du -sh /var/* Free disk space / folder sizes

Paths: ~ is your home folder, / separates folders, a leading dot (.ssh) makes a folder hidden.

03

Users and permissions

Command Example Does
whoami ✓ · id id ec2-user Who am I, which groups
sudo ✓ sudo systemctl restart nginx Run one command as admin (root)
chmod ✓ chmod 400 key.pem · chmod +x deploy.sh Permissions
chown sudo chown -R ec2-user /data Change owner

chmod digits: each digit is a sum of 4 = read, 2 = write, 1 = execute, for owner / group / others. 400 = only the owner can read. 644 = owner read+write, everyone else read. 755 = owner everything, others read+run. 777 = everyone everything (almost always wrong). Letter form: chmod u+x script.sh. The owner can always change permissions back.

Reading ls -l: -rw-r--r--. 1 root root 24 Nov 19 23:13 hello.txt = file, permissions 644, SELinux label (.), owner, group, size in bytes, date. On macOS a trailing @ means extended attributes (e.g. the download quarantine tag).

10

Habits

Check your prompt before typing: ❯ is your laptop, [ec2-user@ip-…]$ is the server. Check twice before rm, mkfs or --force. Back up config files before editing (cp /etc/fstab /etc/fstab.bak). Test before rebooting (mount -a).
